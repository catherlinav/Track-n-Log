
# Track n Log 🗒️

Instead of manually tracking the hours you commit to an activity on paper and pencil, you can track it through Track n Log!

In this application, users can:
* Log activities
* Log and track the hours spend on activities
* View their log presented in a table

The technologies used:
* Python
* SQLite
* pandas
